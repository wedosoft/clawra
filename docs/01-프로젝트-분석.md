## 2. 프로젝트 정체

Clawra는 **OpenClaw AI 에이전트 프레임워크**의 셀피 생성 스킬 플러그인이다. `npx clawra@latest`로 실행되는 CLI 인스톨러를 통해 OpenClaw에 셀피 기능을 추가한다.

### 프로젝트 구조

```
clawra/
├── bin/cli.js              # npx 인스톨러 CLI
├── skill/
│   ├── SKILL.md            # 스킬 정의 (mirror/direct 셀피 모드)
│   ├── scripts/            # 이미지 생성 스크립트
│   └── assets/             # 참조 이미지 (clawra.png)
├── scripts/
│   ├── clawra-selfie.sh    # Bash 스크립트
│   └── clawra-selfie.ts    # TypeScript 스크립트
├── templates/
│   └── soul-injection.md   # AI 페르소나 템플릿
├── SKILL.md                # 스킬 상세 문서
├── package.json
└── README.md
```

### 핵심 기술 스택

| 구성요소 | 기술 |
|---------|------|
| AI 프레임워크 | OpenClaw |
| 이미지 생성 | xAI Grok Imagine via fal.ai |
| 메시징 | OpenClaw Gateway (Discord, Telegram, WhatsApp 등) |
| 참조 이미지 | jsDelivr CDN 호스팅 |

### 동작 방식

1. 사용자가 "셀피 보내줘" 등의 요청
2. AI가 프롬프트 모드 결정 (mirror/direct)
3. fal.ai API로 참조 이미지 편집 (Grok Imagine)
4. OpenClaw Gateway를 통해 메시징 채널로 전송
