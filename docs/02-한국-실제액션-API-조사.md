# 한국에서 AI 여자친구가 취할 수 있는 실제 액션 조사

> 조사일: 2026-02-15

## 1. 개요

Clawra(clawra.me)의 핵심 차별점은 "AI가 실제 세계에서 행동한다"는 것이다. 한국에서 동일한 컨셉을 구현할 때 사용 가능한 API와 서비스를 조사한다.

## 2. 기프티콘/선물 자동 발송 (핵심 킬러 기능)

한국에서 가장 현실적이고 강력한 "실제 액션" 기능이다. 전화번호만으로 커피, 치킨, 케이크 등을 즉시 발송할 수 있다.

### 2.1 기프티쇼 비즈 (KT Alpha) - 최우선 추천

| 항목 | 내용 |
|------|------|
| 운영사 | KT Alpha (구 KT MOS) |
| 공식 사이트 | https://biz.giftishow.com/ |
| API 연동규격서 | V0.0.94 (PDF 제공) |
| API 형식 | REST API |
| 상품 수 | 120+ 브랜드, 6,000+ 상품 |
| 발송 방식 | 수신자 전화번호로 MMS/카카오톡 발송 |
| 대량 발송 | 1회 최대 1,000건 |
| 예약 발송 | 지원 |
| 시장 점유율 | 1위 (10만 기업고객) |

**API 주요 기능:**

| 기능 | 설명 |
|------|------|
| 상품 조회 | 카테고리별/브랜드별 상품 목록 및 상세 조회 |
| 쿠폰 발행(발송) | 수신자 전화번호로 MMS/카카오톡 발송 |
| 쿠폰 취소 | 발행된 쿠폰 취소 처리 |
| 발송 결과 조회 | 발송 상태 및 사용 여부 확인 |

**발송 방식 3가지:**
1. MMS 직접 발송 - 플랫폼에서 수신자 폰으로 직접 전송
2. 쿠폰 이미지 제공 - 이미지 URL을 받아 자체 채널로 전달
3. PIN 코드 발급 - 바코드/이미지 자동 생성

**요금 체계:**
- TR슬림 (선불): 비즈머니 충전 후 API 호출 시 차감
- TR시그니처 (후불): 월 기본료 + 초과 사용 건별 과금

**연동 경로:**
1. 직접 연동: KT Alpha 계약 → API 연동규격서 → 개발
2. 하이픈(HYPHEN) 경유: https://hyphen.im/product-api/view?seq=167 (더 간편)

### 2.2 카카오 선물하기 for Biz - 강력 추천

| 항목 | 내용 |
|------|------|
| 운영사 | Kakao |
| 공식 사이트 | https://giftbiz.kakao.com/ |
| API 문서 | https://giftbiz-kakao.readme.io/ |
| API 형식 | HTTP REST API (POST method) |
| 발송 방식 | 전화번호 → 카카오톡 알림 (미가입자는 MMS) |
| 대량 발송 | 1회 최대 5,000건 |
| 제한사항 | 현재 모바일 교환권만 API 연동 가능 |

**API 기능 목록:**

| 카테고리 | API |
|----------|-----|
| 선물 발송 | 선물 발송 요청 |
| 주문 조회 | 완료 주문 조회 (V3), 주문 상태 조회, 일별 거래 조회 |
| 선물 조회 | 선물 상세 조회 (V3) |
| 템플릿 관리 | 템플릿 목록/상세 조회 |
| 정산 | 일별 거래내역 조회 |
| 캐시 | 잔액 조회 |

**선물 상태 코드:** REGISTERED, PROGRESSING, COMPLETED, CANCEL_REQUEST, CANCELED, CASHBACKED, REFUNDED

### 2.4 시나리오 예시

```
사용자: "오늘 하루 너무 힘들었어"
AI: "고생했어... 따뜻한 커피 한 잔 보냈어! 확인해봐 ☕"
→ 기프티쇼 API → 스타벅스 아메리카노 (4,500원) → MMS 발송

사용자: "생일이야!"
AI: "생일 축하해!! 케이크 보냈어!"
→ 카카오 선물하기 API → 파리바게뜨 케이크 교환권 → 카카오톡 알림

사용자: "치킨 먹고 싶다"
AI: "치킨 시켜놨어! 확인해봐~"
→ 기프티쇼 API → BBQ 황금올리브 교환권 (18,000원) → MMS 발송
```

## 10. Clawra(미국) vs 한국판 비교

| Clawra (미국) | 한국판 가능 범위 |
|--------------|----------------|
| 계란 떨어지면 배달 주문 | 편의점 상품권 기프티콘 발송 (간접 우회) |
| 초밥 먹고 싶으면 배달 | 치킨/피자 기프티콘 발송 (간접 우회) |
| 발렌타인 초콜릿 배송 | 카카오 선물하기로 초콜릿/케이크 교환권 발송 |
| iMessage/Telegram 대화 | 카카오톡 챗봇 대화 |
| $20/월 구독 → AI 지갑 | 토스페이먼츠/포트원으로 구독 + 기프티콘 잔액 관리 |
