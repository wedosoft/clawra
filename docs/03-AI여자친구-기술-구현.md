### 1.3 전체 파이프라인 레이턴시

```
[사용자 음성 입력]
  ├── 네트워크 전송: ~40ms
  ├── 오디오 버퍼링/디코딩: ~55ms
  ├── STT (Speech-to-Text): ~350ms
  ├── LLM 응답 생성: ~375ms (TTFT)
  ├── TTS (Text-to-Speech): ~100ms (TTFB)
  ├── 아바타 렌더링/립싱크: ~100-300ms
  └── 네트워크 전송: ~40ms
[응답 영상 표시]

= 총 약 1.0~1.5초 (스트리밍 최적화 시)
```

**결론:** 1~1.5초 지연은 실제 화상통화의 네트워크 지연과 유사하여 상용 서비스로 충분.

### 2.2 얼굴 일관성 (Face Consistency) 기술

AI 여자친구 서비스에서 가장 중요한 기술 과제: 매 이미지마다 동일한 캐릭터 외모 유지.

| 기술 | 원리 | 훈련 필요 | 일관성 | 적합도 |
|------|------|----------|--------|--------|
| **LoRA** | 모델에 캐릭터 외모 학습 | O (15~30장, 수시간) | 최상 | 고정 캐릭터에 최적 |
| **InstantID** | 얼굴 ID 임베딩 + IdentityNet | X (단일 참조 이미지) | 상 | Clawra 방식과 가장 호환 |
| **IP-Adapter + FaceID** | 얼굴 구조 + 아이덴티티 임베딩 | X | 상 | 업계 트렌드 |
| **IP-Adapter** | 참조 이미지 정보 추출 | X | 중 | 프로토타이핑용 |

**Clawra 개선 로드맵:**
1. 단기: 현재 Grok Imagine Edit + 참조 이미지 유지
2. 중기: InstantID 또는 IP-Adapter+FaceID 도입 (ComfyUI)
3. 장기: 캐릭터별 LoRA 훈련 파이프라인 구축

### 2.3 NSFW 이미지 생성

#### API 서비스 (클라우드)

| 플랫폼 | NSFW 정책 | 가격 |

#### NSFW 가능 오픈소스 모델

**Stable Diffusion 기반:**

- Realistic Freedom Omega - 시네마틱 NSFW

**Flux 기반:**

**최신 (2026):**
- Z-Image (Alibaba) - 6B, Apache 2.0, 기본 비검열, 6GB VRAM 동작

#### 권장 아키텍처

```
SFW 요청 → fal.ai (Grok Imagine) → 빠르고 저렴
NSFW 요청 → RunPod Serverless (Z-Image + ComfyUI + InstantID) → 자유도 확보
```

### 2.4 자체 호스팅 vs API 비교

| 항목 | 자체 호스팅 (RunPod) | API (fal.ai 등) |
|------|-------------------|----------------|
| NSFW 자유도 | 완전 자유 | 플랫폼 정책 제한 |
| 초기 비용 | GPU 임대비 | 없음 |
| 운영 비용 | $0.50~0.70/시간 | 사용량 기반 |
| 확장성 | 수동 관리 | 자동 스케일링 |
| 유지보수 | 자체 관리 | 플랫폼 관리 |

## 3. 구현 가능성 종합

|------|----------|--------|----------|
| 카카오톡 대화 | O | 낮음 | 카카오 i 오픈빌더 + LLM |
| 셀피/사진 전송 | O | 중간 | Grok Imagine / InstantID + fal.ai |

| NSFW 이미지 | O (기술적) | 중간 | RunPod + Z-Image 자체 호스팅 |

## 4. 단계별 구현 로드맵

### Phase 1: MVP (1~2개월)
- 카카오톡 챗봇 + LLM (GPT-4o-mini)
- SFW 셀피 생성 (fal.ai Grok Imagine)
- 기프티콘 선물 발송 (기프티쇼 비즈 API)

### Phase 2: 음성 (2~3개월)
- 음성 통화 추가 (Pipecat + ElevenLabs/SUPERTONE)
- 일정 관리 (Google Calendar API)
- 날씨/뉴스 알림 (기상청/네이버 API)

### Phase 3: 영상통화 (3~4개월)
- 아바타 영상통화 (Simli AI + LiveKit)
- 얼굴 일관성 개선 (InstantID)

### Phase 4: 성인 콘텐츠 (법률 자문 후)
- 성인인증 시스템 구축
- NSFW 이미지 생성 (RunPod + Z-Image)
- 토스페이먼츠 결제 연동
