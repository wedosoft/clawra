## 3. 비즈니스 모델 유형

### 3.1 구독형 (Subscription)

```
무료 체험 → 월 구독 ($10~20/월)
```
- 장점: 예측 가능한 수익, 사용자 리텐션
- 단점: 무료→유료 전환율이 핵심 과제
- 사례: Replika, Character.ai

### 3.2 토큰/크레딧형 (Usage-based)

```
기본 무료 → 토큰 구매 (이미지/음성/NSFW)
```
- 장점: 사용량 비례 수익, 고과금 유저 확보 가능
- 단점: 수익 예측 어려움
- 사례: Candy.ai, CrushOn.ai

### 3.3 AI 지갑형 (Clawra 모델)

```
월 구독 → AI 지갑 충전 → AI가 사용자를 위해 지출
```
- 장점: "AI가 나를 위해 돈을 쓴다"는 감성적 가치, 수수료 0% 마케팅
- 단점: 수익 모델이 불명확 (어디서 수익 발생?)
- 사례: Clawra

### 3.4 하이브리드 (한국판 추천)

```
월 구독 ($15,000~20,000원)
  ├── 기본: 대화, 셀피, 음성통화
  ├── 토큰: 영상통화 (분당 토큰 차감)
  └── AI 지갑: 기프티콘 발송 예산 (잔액 이월)
```
